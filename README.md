# Fall-Detection
A deep learning-based fall prediction and detection system using real-time camera capture. This project aims to enhance elderly care, accident prevention, and medical emergency response by detecting falls and alerting caregivers in real time.
# Features
->Real-time Fall Detection using a webcam or CCTV
->Deep Learning-based Classification (Fall, No Fall, Chest Pain)
->Custom Dataset with real-world scenarios

# Technologies Used
->OpenCV – Real-time video processing
->TensorFlow/Keras – Deep Learning model
->Python – Core implementation

# Dataset
The model is trained on a dataset containing:
->Fall images/videos
->Non-fall activities (walking, sitting, standing)
->Chest pain discomfort (individuals holding their chest)
